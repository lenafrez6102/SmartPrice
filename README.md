# Smart Price Comparison Side Panel (Chrome Extension)

## How to install and view in Google Chrome:

1. **Unzip this folder** to a permanent directory on your computer (e.g. `Documents/SmartPriceComparisonExtension`).
2. Open **Google Chrome** and navigate to:
   `chrome://extensions`
3. In the top-right corner, turn ON **"Developer mode"**.
4. In the top-left corner, click the **"Load unpacked"** button.
5. Select the unzipped extension directory containing `manifest.json`.
6. Click the Extensions (puzzle piece) icon in your Chrome toolbar, pin **"Smart Price Comparison Side Panel"**, and click it!
7. The native Chrome Side Panel will dock to the right side of your browser and stay open as you browse Amazon, Target, Best Buy, Walmart, or eBay. Click **+ Add Current Tab** to extract and compare!
